Fælles arbejdsgang

1. Åbn Wokwi-linket til ESP32-S3 med MicroPython. 2. Opret komponenter og forbindelser i diagrammet. 3. Skriv din kode i main.py. 4. Tryk Start Simulation, og undersøg terminalen. 5. Gem og del projektlinket, og dokumentér dine test.

VS Code: Når øvelserne fungerer i browseren, kan eleverne arbejde i VS Code. Wokwis MicroPython-workflow i VS Code kræver yderligere opsætning; på rigtigt hardware skal kode overføres til boardet.

Lærernote

For øvelser med knapper, sensorer og displays skal eleverne selv tilføje komponenter i Wokwi. Wokwi-knapperne åbner et tomt ESP32-S3 DevKitC-1, ikke en færdig kopi af dit specialfremstillede print. Tilføj selv komponenter og forbind dem til de samme GPIO-numre. Senere kan hvert emne få sit eget prækonfigurerede Wokwi-projekt.

MicroPython-versioner varierer. Brug if/elif/else som sikker introduktion til valg, og behandl match/case som en mulighed, der skal afprøves i den valgte version.
